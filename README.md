# Пульт Целителя — Telegram Mini App B1

Тестовый frontend принятой формы A2.2 для проверки внутри Telegram.

- только искусственные данные;
- без bridge-секретов и токенов;
- без личного pult.json и реальной Медкарты.

B1.1 исправляет только публикационный слой: отдельные JS/CSS/assets вместо повреждённого self-contained HTML; шрифты публикуются явно.
