# Пульт Целителя — Telegram Mini App B1

Публичный тестовый frontend принятой Telegram-формы A2.2.

- Только искусственные данные.
- Не подключён к личному `pult.json`.
- Не читает и не изменяет Медкарту.
- Не содержит bridge-секретов, токенов или персональных медицинских данных.
- Назначение: B1 — проверка реального Telegram Mini App shell перед подключением транспорта к Mac.
